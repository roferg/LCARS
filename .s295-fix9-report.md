# S295 fix 9: unattended commands write downward

## Rule placement

`skills/lcars-buddy/AUTOPILOT.md` now has **Unattended Copilot commands:
start at the repository root and write downward**, immediately after the
directory-trust setup and before **How to read this file**, Foundation, and
project testing. Verify also links back to the rule for readers jumping
directly to that section.

The rule requires repository-root commands and downward writes, forbids
redirecting through parent components even when the destination remains inside
the repository, and explains that blanket trust does not prevent this refusal.
An unattended agent cannot obtain interactive approval, so refusal ends the
run rather than inviting a retry. The real failing command is clearly marked
as documentation only, not to execute; the working example discovers the
nested worktree's tests from the root and writes to
`.git/lcars/autopilot/x.txt`.

The existing trust warning did not cover this command-route restriction.
