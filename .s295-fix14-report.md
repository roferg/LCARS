# S295 fix14: stopped at the deliberate-exclusion challenge

## Verdict: deliberate omission, not a requirements/derive race

The requested stop condition is met. No production code, capture contract, or
tests were changed. The only committed change is this report.

`web/lcars_serve/actions.py` assembles the text in `_handoff_brief` (line 3381).
It calls `_handoff_parts`, which reads the recorded requirements from
`concept.md` through `_handoff_requirements`. However, `_handoff_brief` names
that result `_reqs` and never renders it. `holodeck_promote` independently
publishes those same captured items in the response's `requirements` array.
Finishing derive cannot restore them to the brief: derive supplies `changes`
and `asks`, not the requirements section.

This is explicitly intentional, not merely an unused variable:

- The S171 explanation at lines 2823-2849 records the decision to remove the
  turn-attributed requirements list because it read as a conversation timeline
  rather than an app specification.
- Lines 3429-3484 explain both the removal of the missing-requirements check and
  the replacement guarantee: the complete `concept.md` travels as an attachment.
- `file_mission` and `park` resolve the Program's mockup and concept document
  through `_handoff_attach` and pass both as repeated `--attach` arguments.
  `skills/lcars-file/file.sh` copies those attachments into durable Mission
  storage; its park path does so at lines 532-546.
- Existing endpoint tests explicitly assert this contract.
  `HandoffRequirementsTest.test_the_captured_requirements_reach_the_FILED_MISSION_verbatim`
  asserts that the requirement is absent from the filed idea but present in the
  attached concept document. `HandoffRequirementCheckIsGONETest` protects the
  same separate-supply road.

Pasting the captured requirements back into the brief would therefore duplicate
content already supplied downstream and reverse a documented product decision.
Under the request's challenge clause, implementation stopped rather than
changing that contract or writing a deliberately contradictory regression.
