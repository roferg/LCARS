# Fix 4: terminal missions cannot hold the conn

## Layer decision

**Presentation only**, in `web/static/board.js`. Done is terminal: the board
already deliberately supplies no primary action for it. Number One's appended
controls and current-activity messaging were bypassing that decision.

The shared presentation predicate now treats an engaged flag as current only
before Done. The engaged pill and conn sentence use that same decision.
Historical grades, reports, finished/stood-down history, and active mission
controls remain available; a stale engaged transcript is not newly exposed.

No mission state or completion writer was changed. This intentionally corrects
records already on disk without fabricating a finished investigation or
rewriting history. A state-only change would leave tonight's broken cards
wrong. This is not a second fix for Done rendering as paused.
