# Context manifest — t-001: Extend the snapshot data model

## Relevant files
- `shared/types.ts` — the data contract; add the optional fields to `Kpi` and `Snapshot`.
- `src/lib/data.ts` — consumers of `Snapshot`/`Kpi` (glob load, ordering, seeding helpers).
- `scripts/build-snapshot.ts` — builds `Snapshot` objects; new fields must remain optional.
- `data/snapshots/*.json` — existing locked/draft snapshots that must still load without the new fields.
